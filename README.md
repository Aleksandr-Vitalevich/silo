# 🛡️ Silo Core — Релиз v2.5

Официальное обновление архитектуры и функционала локального менеджера безопасности. Проект успешно переведен с концепта MVP Personal Manager на полноценный монолитный фреймворк **Streamlit** с фокусом на 100% автономность (0% интернета), конфиденциальность и скорость работы.

---

## 🚀 Ключевые изменения в версии 2.5

### 1. 🧠 Интеграция локального ИИ-Ассистента (Ollama Engine)
* **Полная автономность:** Модуль ИИ работает локально через движок `Ollama` (модель `Llama 3`), не отправляя ни единого байта данных в сеть.
* **Контекстная память диалога (In-Memory):** Переписка переведена на эндпоинт `/api/chat`. Архитектурный список сообщений хранится строго в `st.session_state` и автоматически очищается из оперативной памяти при закрытии приложения.
* **Изолированный Системный Промпт:** Инструкция бортового компьютера вынесена из общего списка сообщений и подклеивается динамически на бэкенде. ИИ жестко зафиксирован на русский язык общения и суровый стиль секретного бункера.
* **Разделение UX интерфейса:** Модуль искусственного интеллекта разделен на две изолированные подвкладки:
  * `Беседа` — для свободного диалога и технических консультаций.
  * `Анализ` — выделенное окно для отчетов без захламления основного чата.

### 2. 📊 Интеграция ИИ с Архивами Дневника (Stateless-Аналитик)
* **Ретроспективный анализ:** Внедрена система извлечения последних записей из Дневника пользователя (`LIMIT ?`). Количество записей для анализа динамически регулируется пользователем через виджет `st.slider`.
* **Безопасная дешифрация "на лету":** Логика извлечения сырых байтов SQLite и дешифрации Fernet разделена по правилам SOLID. Записи расшифровываются с помощью `master_password` непосредственно перед отправкой ИИ и хранятся только в кэше текущей сессии.

### 3. 🛠️ Рефакторинг Ядра и Оптимизация Базы Данных
* **Ликвидация Бага Блокировки SQLite:** Устранена критическая ошибка `"database is locked"`. Все вызовы переведены на строгий single-call паттерн, а проверка существования пользователя оптимизирована и кэшируется в сессии.
* **Устранение эха в логировании:** Из-под тяжелого декоратора `@db_logger` выведены микро-утилиты шифрования (`hash_password`, `check_password`, `encrypt_text`, `decrypt_text`). Нагрузка на процессор при авторизации через Bcrypt снижена в 2 раза.
* **Совместимость данных:** Имя файла базы данных временно сохранено как `personal_manager.db` для 100% обратной совместимости со стабильной версией архивов.

## 🏗️ Текущий Стек Технологий (v2.5)
* **Frontend/Backend:** Streamlit (Монолитная архитектура сессий)
* **База данных:** SQLite 3
* **Криптография:** Fernet (симметричное шифрование данных) + Bcrypt (хэширование паролей авторизации)
* **Локальный ИИ:** Ollama API (`/api/chat` эндпоинт, модель `Llama 3`)
