# Silo — Релиз v2.6

Официальное глобальное обновление архитектуры, безопасности и интерфейса локального менеджера конфиденциальности. Проект успешно переведен на монолитную структуру **Streamlit**, избавился от критических багов ядра, обзавелся автономным ИИ-модулем и подтвердил свою 100% кроссплатформенность в ходе боевого тестирования.

---

## 💎 Главные достижения и реализованный функционал

### 1. Эволюция интерфейса (Переезд в st.sidebar)
* **Десктопный формат:** Горизонтальные вкладки полностью ликвидированы. Навигация по всем отсекам крепости перенесена в левую боковую панель `st.sidebar.radio`.
* **Стабилизация рендера:** Благодаря фиксации фокуса в сайдбаре полностью решена проблема «прыжков» интерфейса на первую вкладку при обновлении страницы.
* **Шпионский CSS-стиль:** Через инъекцию кастомных стилей из интерфейса полностью удалена системная шапка Streamlit (кнопки Deploy и основное меню), что превратило приложение в чистый изолированный десктопный продукт.

### 2. Автономный ИИ-Ассистент с контекстной памятью
* **0% Интернета:** Интегрирован движок `Ollama` (модель `Llama 3`), работающий полностью локально на мощностях процессора/видеокарты.
* **Умный Чат (In-Memory):** Взаимодействие переведено на эндпоинт `/api/chat`. Вся история переписки хранится в оперативке сессии (`st.session_state`) и бесследно стирается при закрытии программы.
* **Скрытый Системный Промпт:** Инструкция бортового компьютера вынесена из общего списка сообщений и подклеивается на бэкенде. ИИ жестко зафиксирован на русский язык общения и суровый стиль секретного бункера.
* **Разделение UX:** Интерфейс ИИ разделен на две изолированные подвкладки: `Беседа` (свободный диалог) и `Анализ` (вывод аналитики архивов).
* **Глубокий анализ Дневника:** Реализована система извлечения последних записей из Дневника пользователя (`LIMIT ?`). Количество записей регулируется виджетом `st.slider`. Данные расшифровываются мастер-паролем «на лету» строго в память перед отправкой ИИ.

### 3. Интерактивный Календарь-Ежедневник
* **Зашифрованная база данных:** Спроектирована новая таблица `calendar_tasks` в SQLite. Названия и описания задач надежно защищены симметричным шифрованием Fernet.
* **Интерактивные чекбоксы:** Задачи на выбранный день (через `st.date_input`) выводятся списком с отображением приоритетов. Клик по галочке мгновенно перезаписывает статус задачи (`is_completed: 0/1`) в SQLite.
* **Локальная оценка нагрузки:** Под списком планов добавлена кнопка ИИ-анализа расписания, которая оценивает загруженность дня и выдает краткие рекомендации.

### 4. Рефакторинг Ядра и Кроссплатформенная Сборка
* **Ликвидация Database Locked:** Полностью устранена критическая ошибка блокировки SQLite за счет оптимизации single-call паттернов и кэширования авторизации.
* **Снижение нагрузки на CPU:** Из-под тяжелого декоратора `@db_logger` выведены утилиты шифрования, что ускорило прогон Bcrypt при входе в систему в 2 раза.
* **Боевой тест на Linux & PyInstaller:** Написана кроссплатформенная Python-обертка для запуска. Проект успешно упакован через `pyinstaller --onefile` на операционной системе Linux, подтвердив стабильность логики, путей и отказоустойчивость ядра при «сухом» запуске без ИИ.

## 🏗️ Текущий Стек Технологий (v2.6)
* **Интерфейс и Диспетчеризация:** Streamlit (Монолитная архитектура, кастомный CSS, `st.sidebar`)
* **Сборщик дистрибутива:** PyInstaller (Компиляция в один независимый бинарный файл под целевую ОС)
* **База данных:** SQLite 3 (Централизованная инициализация, single-thread транзакции)
* **Криптография и Безопасность:** Fernet (симметричное шифрование данных) + Bcrypt (хэширование паролей авторизации)
* **Локальный искусственный интеллект:** Ollama API (эндпоинт `/api/chat`, модель `Llama 3`)
* **Автоматизация среды:** Bash-скриптинг (`run_desktop.sh` для изоляции виртуального окружения `.venv`)
