# Silo — Релиз v2.7
---
Проект является своеобразным хранилищем для данных. Использует концепцию одна копия -> один пользователь . Поскольку это сейф для данных рекомендация сохранить ваш логин и пароль чтобы не потерять доступ к данным . Восcтановить их не получится . 

### ___Пакет db_manager___
> Содержит логику работы с базой данных<br>
> Проект использует sqlite3 в корне проекта при первом запуске создается файл БД `personal_manager.db`<br>
> В программе может быть зарегестрирован только один пользователь , логин и пароль лучше записать поскольку шифрование данных происходит на основе пароля и восстановить его не получится.<br>
---
### ___Пакет utils___
> Содержит утилиты такие как декораторы `logger.py`, `input_cleaner.py`, `retry.py` <br>
> логику шифрования смотри модуль `security.py`<br>
> логику работы с ollama. В проекте используется локальный ии модель `llama3`. При желании можете выбрать другую или не подключать работать программа будет. Для работы нужно будет установить `ollama` или включить.
---
### ___Пакет view___
> Интерфейс программы. Компоненты интерфейса
- Данные (Сохранение , просмотр, редактирование ваших паролей , логинов и остального что хотите сохранить)
- Дневник (Можете писать свои мысли , идеи). Можно загружать из файла txt
- Ассистент (Можно побеседовать с локальной версией ии агента)
- Календарь и заметки (Можете выбирать день и добавлять заметки есть возможность выбора приоритета и отмечать выполненные пункты) . Возможность редактирования . 
- Карты и заметки (откроется карта по умолчанию Екатеринбург , можете ставить метку на карте и добавлять заметки)
- Выход меню выхода

### ___Скрипт запуска для Mac Os и Linux Mint___
> Алгоритм 
- Скачиваем код , распаковываем . Ничего из проекта не удаляем .
- Открываем папку через терминал. Просто нажимаем правой кнопкой мыши по папке и выбираем пункт открыть через терминал или похожий.
- У вас откроется окно вверху будет надпись имя пользователя системы и строчки которые будут заканчиваться названием папки.
- Вводим следующие команды 
```
chmod +x run_desktop.sh
./run_desktop.sh
```
> 1 Команда один раз делает папку исполняемой 2 Команда Запуска. <br>
> В последствии выполняем только ее <br>
> Файлы из папки никуда не перемещать . Нужно переместить , перемещаем саму папку. <br>

> Алгоритм установки
- Первые шаги те же. Если проделали их делать не нужно повторно.
- Вводим эти три команды 
```
source .venv/bin/activate 
pip install pyinstaller
pyinstaller --onefile --windowed --name "SiloCore" app_runner.py
```
- 1 Команда запускает виртуальное окружение , чтобы использовать компоненты программы и чтобы запустить без дополнительных зависимостей 2 команду
- 2 Команда запускает установку сборщика программы.
- 3 Команда запускает сборку
- Команды создадут папку Dist, а в ней два файла для Mac Os просто копируем оба файла в общую папку проекта . Если Linux то будет один файл саму папку dist можно потом удалить.

### ___Скрипт запуска для Windows___
> Алгоритм запуска
- Скачиваем код , распаковываем . Ничего из проекта не удаляем .
- Заходим в папку находим файл `run_desktop.bat` нажимаем правой кнопкой -> открываем в блокноте. В верхнем меню Блокнота нажмите Файл -> Сохранить как
- Внизу открывшегося окна найдите пункт Кодировка (Encoding) -> меняем на ANSI (или Windows-1251). Соглашаемся со всем при сохранении. 
- Закрываем блокнот и кликаем по файлу `run_desktop.bat`
- Система будет устанавливать зависимости ждем после установки окно браузера автоматически откроется . 
- Дальнейшее использование просто кликаем по файлу `run_desktop.bat`
- Последующие запуски будут быстрее.
> Файлы из папки никуда не перемещать . Нужно переместить , перемещаем саму папку.
