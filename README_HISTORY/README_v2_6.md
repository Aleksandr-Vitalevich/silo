# Silo — Релиз v2.6

Официальное глобальное обновление архитектуры, безопасности и интерфейса локального менеджера конфиденциальности. Проект успешно переведен на монолитную структуру **Streamlit**, избавился от критических багов ядра, обзавелся автономным ИИ-модулем и подтвердил свою 100% кроссплатформенность в ходе боевого тестирования система развернулась на mac-os и linux mint.

---

##  Реализованный функционал

### 1. Эволюция интерфейса (Переезд в st.sidebar)
- Горизонтальные вкладки полностью ликвидированы. Навигация перенесена в левую боковую панель `st.sidebar.radio`.

### 2. Автономный ИИ-Ассистент с контекстной памятью
- Интегрирован движок `Ollama` (модель `Llama 3`), работающий полностью локально на мощностях процессора/видеокарты
- Взаимодействие переведено на эндпоинт `/api/chat`. Вся история переписки хранится в оперативке сессии (`st.session_state`).
- Интерфейс ИИ разделен на две изолированные подвкладки: `Беседа` (свободный диалог) и `Анализ` (вывод аналитики архивов).
- Реализована система извлечения последних записей из Дневника пользователя (`LIMIT ?`). Количество записей регулируется виджетом `st.slider`. Данные расшифровываются мастер-паролем «на лету» строго в память перед отправкой ИИ.

### 3. Интерактивный Календарь-Ежедневник
- **Спроектирована новая таблица `calendar_tasks` в SQLite**.

---

## 🏗️ Текущий Стек Технологий (v2.6)
- **Интерфейс и Диспетчеризация:** Streamlit (Монолитная архитектура, кастомный CSS, `st.sidebar`)
- **Сборщик дистрибутива:** PyInstaller (Компиляция в один независимый бинарный файл под целевую ОС)
- **База данных:** SQLite 3 (Централизованная инициализация, single-thread транзакции)
- **Криптография и Безопасность:** Fernet (симметричное шифрование данных) + Bcrypt (хэширование паролей авторизации)
- **Локальный искусственный интеллект:** Ollama API (эндпоинт `/api/chat`, модель `Llama 3`)
- **Автоматизация среды:** Bash-скриптинг (`run_desktop.sh` для изоляции виртуального окружения `.venv`)
