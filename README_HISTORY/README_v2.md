# 🔐 Personal Manager v2.0 - Standalone Release

Персональный менеджер со встроенным шифрованием данных и личным дневником. Приложение полностью автономно и разворачивает изолированную среду выполнения (`.venv`) при первом запуске на целевой машине.

---
## Использован фреймворк STREAMLIT
## База данных Sqllight
## Приложение с иконкой собирается протестировано на Мак. Скрипт расчитан на запуск и в среде Linux (возможна необходимость в доработке)
- Запуск скрипта если не собирать приложение. Открываем терминал по адресу папки. Вводим команды
- `chmod +x run_desktop.sh` -> В терминале вводится один раз. Делает скрипт исполняемым
- `./run_desktop.sh` -> Запуск приложения
> Работает для Mac Os и Linux

## 🛠 Инструкция по компиляции (Для разработчика)

Для сборки автономной иконки запуска используется утилита `PyInstaller`. Сборка производится из корня рабочего проекта (виртуальное окружение должно быть активировано):

```bash
pyinstaller --clean --onefile --windowed --name="PersonalManager" --distpath="../PersonalManager_Release" --workpath="../pyinstaller_build" app_runner.py
```

### Что делают флаги:
* `--clean` — Полная очистка кэша сборщика перед компиляцией.
* `--onefile` — Упаковка исполняемого файла запуска в монолитный бандл.
* `--windowed` — Графический режим (скрывает черные окна системной консоли при старте).
* `--distpath` — Вынос готового продукта в отдельную чистую папку релиза за пределы рабочего репозитория.

## 📦 Структура готовой папки дистрибутива (Для работы программы)

Чтобы скомпилированное приложение успешно развернуло окружение и запустило интерфейс, в папке релиза (`PersonalManager_Release`) **строго на одном уровне** должны находиться следующие файлы и каталоги:

```text
PersonalManager_Release/
│
├── PersonalManager.app (или PersonalManager.exe) # Главная иконка запуска программы
├── run_desktop.sh (или run_desktop.bat)          # Системный скрипт автоматизации портов и venv
├── main_operation.py                             # Диспетчер интерфейса Streamlit
├── requirements.txt                              # Список зависимостей проекта (bcrypt, streamlit и др.)
├── personal_manager.db                           # Скопированная заполненная база данных СУБД SQLite
│
├── .streamlit/                                   # Скрытая папка с файлом конфига config.toml (стили страниц)
├── db_manager/                                   # Модуль функций бэкенда и работы с базой данных
├── view/                                         # Модуль графических вкладок (табов) интерфейса
└── utils/                                        # Модуль утилит (логирование, input-клинеры, декораторы)
```

## 🚀 Как запустить программу на новом компьютере (Для пользователя)

1. Перенесите готовую папку `PersonalManager_Release` на целевой компьютер (например, через флешку).
2. **Первый запуск (Инициализация):** Дважды кликните по файлу автоматизации `run_desktop.sh`. Программа в фоновом режиме сама создаст скрытую изолированную папку `.venv` и с помощью локального `pip` установит все необходимые библиотеки. Сразу после этого откроется бесшовное изолированное окно браузера с формой входа.
3. **Последующие запуски:** В дальнейшем вы можете запускать систему как через скрипт автоматизации, так и обычным двойным кликом по красивой нативной иконке приложения `PersonalManager.app` без участия Терминала.
